# So2Sat_POP Dataset Implementation Summary

## Overview

This implementation adds support for the So2Sat_POP dataset to the UCVME framework. The structure is designed to be extensible for adding more datasets in the future.

## Files Created/Modified

### New Files

1. **`configs/datasets/so2sat_pop.yaml`**
   - Configuration file for So2Sat_POP dataset
   - Defines data paths, image format, target column, etc.

2. **`datasets/base_dataset.py`**
   - Abstract base class for all regression datasets
   - Defines common interface and shared functionality

3. **`datasets/so2sat_pop.py`**
   - So2Sat_POP dataset implementation
   - Handles TIFF image loading, CSV parsing, path resolution
   - Supports automatic FileList.csv generation

4. **`datasets/dataset_factory.py`**
   - Factory pattern for creating dataset instances
   - Registry of available datasets
   - Configuration loading and validation

5. **`utils/config_loader.py`**
   - YAML configuration loading utilities
   - Config validation

6. **`ucvme.py`**
   - Generalized main training script
   - Supports dataset selection via `--dataset` parameter
   - Maintains compatibility with existing training functions

7. **`scripts/generate_filelist_so2sat.py`**
   - Standalone script to pre-generate FileList.csv
   - Useful for debugging and faster startup

8. **`SO2SAT_USAGE.md`**
   - Usage guide for So2Sat_POP dataset

### Modified Files

1. **`datasets/__init__.py`**
   - Added exports for new dataset classes and factory functions

## Key Features

### 1. Automatic FileList Generation
- If `FileList.csv` doesn't exist, it's automatically generated by scanning the directory structure
- Handles both Part1 and Part2
- Validates that images exist before adding to file list

### 2. Flexible Path Resolution
- Supports complex nested directory structure
- Template-based path resolution: `{city_dir}/sen2{season}/Class_{class}/{grd_id}_sen2{season}.tif`
- Configurable season selection

### 3. SSL Split Support
- Compatible with existing SSL split generation
- Supports labeled/unlabeled splits
- SSL multiplier for balancing labeled/unlabeled data

### 4. Image Handling
- Supports multi-channel TIFF images (Sentinel-2, 10 bands)
- Option to use only RGB channels (first 3) for ResNet compatibility
- Automatic normalization

### 5. Target Normalization
- Automatic computation of target statistics (mean, std)
- Can be overridden via command-line parameters

## Usage

### Basic Training

```bash
python ucvme.py \
    --dataset so2sat_pop \
    --data_root /work/ammar/sslrp/data \
    --output ./outputs/so2sat_experiment \
    --rd_label 1000 \
    --rd_unlabel 5000
```

### Pre-generate FileList

```bash
python scripts/generate_filelist_so2sat.py \
    --data_root /work/ammar/sslrp/data \
    --season spring
```

## Architecture Decisions

### 1. Base Dataset Class
- Provides common interface for all datasets
- Handles image normalization, augmentation
- Defines required methods that subclasses must implement

### 2. Configuration-Driven
- Dataset-specific settings in YAML files
- Easy to modify without code changes
- Supports different configurations per dataset

### 3. Factory Pattern
- Centralized dataset creation
- Easy to add new datasets by registering them
- Validates configurations

### 4. Backward Compatibility
- Original `ucvme_age.py` still works for UTKFace
- New `ucvme.py` supports multiple datasets
- Existing training functions reused

## Testing Checklist

Before using in production, verify:

- [ ] FileList.csv generation works correctly
- [ ] Images load correctly (check channel count)
- [ ] Target values are correct (population counts)
- [ ] SSL splits are generated properly
- [ ] Training loop runs without errors
- [ ] Validation/test splits work
- [ ] Checkpoint saving/loading works

## Future Enhancements

When adding more datasets:

1. Create new dataset class inheriting from `BaseDataset`
2. Create corresponding YAML config file
3. Register in `dataset_factory.py`
4. Test with small subset first

## Notes

- The dataset automatically handles missing images (skips them during FileList generation)
- Path resolution is done at dataset initialization, not at runtime (for performance)
- FileList.csv is saved in the dataset directory for reuse
- SSL splits are generated in the main script, not in the dataset class
